Landed Cost Calculator

A single-file, multi-product landed cost calculator for consumer electronics trading. Works for any country to any country.

Features
Multiple products per order with per-unit landed cost and margin
Freight, insurance, bank fees and other costs, split across products by goods value
VAT/GST (recoverable or counted as cost), customs duty and other taxes
Live exchange rates (ECB via Frankfurter) with an offline fallback
Saved product list (stored in your browser)
Download a customer quote (HTML) or CSV. Landed cost and margin are never included in the quote.
Run locally

Open index.html in any browser. No build step or dependencies.

Deploy

Hosted with GitHub Pages from the main branch, root folder.

Disclaimer

Duty and VAT defaults are estimates only. Confirm HS codes, duty and VAT with your customs broker or the relevant authority.
